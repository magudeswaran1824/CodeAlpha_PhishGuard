
# 🛡️ PhishGuard – Phishing Awareness Training Platform

## 1. Introduction

PhishGuard is a cybersecurity awareness platform developed to educate users about phishing attacks and online security threats.

The project helps users understand phishing techniques, identify suspicious emails, recognize fake websites and improve their online safety.

## 2. Objectives

- Educate users about phishing attacks.
- Explain common phishing techniques.
- Identify warning signs in suspicious messages.
- Provide cybersecurity safety tips.
- Test user knowledge through an interactive quiz.

## 3. Technologies Used

- HTML5
- CSS3
- JavaScript
- Visual Studio Code

## 4. Features

1. Responsive Home Page
2. Phishing Awareness Information
3. Email Phishing Examples
4. Common Warning Signs
5. Cybersecurity Safety Tips
6. Interactive Quiz
7. Automatic Score Calculation
8. Quiz Restart Functionality

## 5. Project Structure

PhishGuard/

## 6. Installation and Execution

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html using a browser.
4. Alternatively, use the VS Code Live Server extension.
5. Explore the learning sections and complete the quiz.

## 7. Expected Output

The application displays a cybersecurity awareness website with educational content, phishing examples, safety recommendations and an interactive quiz.

## 8. Future Enhancements

- User registration and login.
- Additional phishing awareness modules.
- More interactive security scenarios.
- Learning progress tracking.
- Additional quiz categories.

## 9. Conclusion

PhishGuard provides a simple and interactive way to understand phishing attacks and develop safer online habits.
